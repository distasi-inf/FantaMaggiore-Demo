# Fantamaggiore

Applicazione web di fantacalcio tra amici con dinamiche di community 
(sfide, classifiche, punteggi ed eventi live).

## Stack tecnico
- **Backend:** Java, Spring Boot
- **Frontend:** Angular, TypeScript, Tailwind CSS, daisyUI
- **Database:** Supabase (PostgreSQL)
- **Deploy:** Vercel (frontend), Render (backend)

## Funzionalità principali
- Gestione ruoli admin/utente
- API REST per gestione tornei, giornate, squadre e match
- Motore di aggiornamento classifiche in tempo reale basato sugli eventi di gioco
- Sistema di sfide/scommesse tra utenti

## Note
Progetto sviluppato individualmente per approfondire l'architettura 
di un'applicazione full-stack completa, dalla progettazione del backend 
al deploy in produzione.
